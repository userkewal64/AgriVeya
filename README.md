# 🌱 AgriVeya
### Climate-Smart Agriculture & Crop Rotation

AgriVeya is a climate-informed agricultural decision-support platform that helps farmers make smarter 
crop rotation decisions using NASA POWER climate data and crop characteristics.

## ✨ Features
- Automatic user location detection.
- Location-based climate information.
- NASA POWER climate data integration.
- Seasonal crop rotation recommendations.
- Previous crop-based planning.
- Responsive and user-friendly interface.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Climate Data:** NASA POWER API
- **Deployment:** Cloudflare Pages & Render

## 🚀 Live Demo
- **Website:** https://agriveya.pages.dev
- **Backend:** https://agriveya.onrender.com

## 💻 Local Setup

```bash
git clone https://github.com/userkewal64/AgriVeya.git
cd AgriVeya/Backend
npm install
npm start
```

Open the `Frontend` folder using a local development server.

## 🛰️ Data Source
[NASA POWER](https://power.larc.nasa.gov/)

## ⚠️ Disclaimer
AgriVeya provides experimental, rule-based agricultural recommendations for planning and educational purposes. 
Recommendations are not guaranteed yield predictions or substitutes for local agricultural expertise.
